# ORBIT engineering roadmap

## Included
- Deterministic planner and SQL template builder.
- Read-only SQL validator and allow-listed demo schema.
- Synthetic retail data warehouse.
- FastAPI endpoints and React analytics workspace.
- Results table, chart, SQL inspector and agent trace.
- Unit/workflow tests, Docker and CI.

## Next milestones
1. Build a reviewed 100+ question text-to-SQL gold benchmark.
2. Add a semantic layer for governed metric definitions.
3. Add clarification when user questions are ambiguous.
4. Add optional LLM adapter with structured output, retries, timeouts and token/cost tracking.
5. Harden SQL with a parser, resource limits, query timeout and adversarial testing.
6. Add authentication, tenant isolation, audit events and row-level policies.
7. Add PostgreSQL adapter, migrations, pooling and backups.
8. Add structured logs, traces, metrics and p50/p95 latency monitoring.
9. Deploy frontend/API, configure secrets, smoke tests and uptime monitoring.
