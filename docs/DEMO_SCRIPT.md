# 3-minute demo script

1. Show the ORBIT workspace and API connection status.
2. Ask `What is our total revenue?`
3. Walk through Planner, SQL Builder, Safety Critic, Executor and Analyst.
4. Open SQL Query and explain the SELECT-only boundary.
5. Ask `Show monthly revenue for 2024` and show the chart.
6. Open Data Catalog and explain the synthetic schema.
7. Export CSV and close with benchmark plan and known limitations.
